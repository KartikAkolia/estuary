indepth:
  - heading: "Probability: a way of measuring uncertainty, not guessing"
    body: >
      Probability gives a precise, numerical way to talk about how likely
      something is — a number between 0 (impossible) and 1 (certain) rather
      than a vague "probably" or "unlikely." A useful way to think about it:
      probability is a formal way of handling situations where you can't be
      certain of the outcome, but you can still reason about it precisely —
      for example, working out the chance a randomly chosen bit in a string
      is a 1, or the chance a system fails within a given time window. A
      "random variable" isn't literally random or a variable in the
      programming sense — it's a function that assigns a probability to
      each possible outcome, which is what lets probability be manipulated
      with the same algebraic tools as everything else in maths.
  - heading: "Descriptive statistics: summarising instead of listing"
    body: >
      Given a large set of data, looking at every individual value tells
      you almost nothing useful — statistics is about compressing that into
      a small number of meaningful summaries. The mean gives a single
      "typical" value; the standard deviation tells you how spread out the
      data is around that mean, so two data sets with the same average can
      still look completely different once you know how much they vary.
      These aren't just exam concepts — they're exactly what's underneath
      phrases like "average response time" or "95th percentile latency"
      that come up constantly once you're actually building or measuring
      real systems.
  - heading: "Where this feeds into computer science specifically"
    body: >
      This module builds directly on the Term 1 foundation, extending the
      same numerical and statistical toolkit to a level meant to prepare
      you for the more demanding, Level 5 (Year 2) computer science maths
      modules later in the degree. Probability underpins randomised
      algorithms (algorithms that use randomness as part of how they work),
      analysing how long an operation takes on average rather than in the
      worst case, and reasoning about machine learning systems, which are
      fundamentally built on probability and statistics rather than
      hard-coded rules.
